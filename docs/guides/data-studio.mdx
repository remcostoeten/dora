---
title: Data Studio
description: Browse, filter, sort, edit, import, and export table data in Dora's spreadsheet-style grid.
---

The Data Studio is Dora's table browser. Click a table in the sidebar to open it
in a fast, virtualized grid that handles large tables without freezing.

## Browse, sort, and paginate

- **Sort** by clicking a column header; click again to reverse, once more to
  clear.
- **Paginate** from the status bar at the bottom; it shows the current row
  range (e.g. `1–50 of 1,240`) with a page size you can change.
- **Refresh** the current table with `Mod+R`.
- **Follow foreign keys** by clicking the badge on a foreign-key cell to jump
  straight to the referenced row.

## Keyboard

With a cell focused:

- **Arrow keys** move the focus, and **Shift+Arrow** extends the selection
  rectangle.
- **S** toggles the sort on that cell's column.
- **Shift+F10** or the **Menu** key opens the cell context menu.
- **Backspace** clears every selected cell, or the focused cell when nothing is
  selected. Primary key cells are skipped.

Cells are type-aware: numbers, booleans, `NULL`, and JSON render distinctly, and
binary columns show a `BLOB` badge with view/copy/export actions. PostgreSQL
arrays, ranges, enums, composites, `inet` and `cidr`, `tsvector`, and `pgvector`
values are shown as readable values.

Open **Row details** from a row to see every field of that row in a dialog.

## Filter

Press `Mod+F` to open the filter bar. Build one or more conditions from a
column, an operator (`=`, `≠`, `>`, `<`, contains, and others), and a value, and
combine them with AND/OR. Filters apply to what you see, and to what you
[export](/docs/guides/export).

## Edit data

- **Edit a cell** by clicking it and typing; the change commits when you press
  Enter or click away. Pending edits are highlighted until saved.
- **Add a row** with `Mod+Shift+I`, fill the draft row, and save.
- **Delete** selected rows with `Backspace` / `Delete`.
- **Bulk edit** multiple selected rows at once from the row context menu.

There are also dialogs to **add or drop a column** and **drop a table**, reached
from the table header or context menu.

<Callout type='warn'>
	Edits, deletes, and dropping columns or tables run real SQL against the connected database.
	There is no undo, so take a backup before destructive changes.
</Callout>

## Import and export

- **Import CSV** from the toolbar: pick a file and map its columns to the table.
  Dora detects whether the file uses commas, semicolons, or tabs, and strips a
  UTF-8 byte order mark from the start of the file.
- **Export** with `Mod+E` (or the toolbar) to CSV, JSON, or SQL `INSERT`
  statements. See the [Export guide](/docs/guides/export) for scope options.

To copy the whole database to disk, see [Dump and restore](/docs/guides/database-dump).

## Compare two CSV exports

When a data-file session holds two or more CSV files, **Compare followers**
lists the rows that are in the older file but missing from the newer one. Pick
the older file, the newer file, and a column both files share, such as a user
name or ID. A typical use is comparing two follower exports to see who
unfollowed. The comparison stops at 10,000 rows.

## Watch a table change live

Open the live monitor with `Mod+Shift+M` to see inserts, updates, and deletes
made by other clients in near-real time. See
[Live change monitoring](/docs/guides/live-monitoring).
