title: Installation
description: Download and install Dora on macOS, Windows, and Linux, or build it from source.

Dora is a native desktop application built with Tauri. Download a prebuilt
installer for your platform, install from the Arch User Repository, or build it
from source.

The fastest path is the downloads page, which always points at the latest
release assets:

<Callout type='info'>
	Get the latest build at [doradb.app/downloads](https://doradb.app/downloads), or browse every
	asset on the [GitHub releases page](https://github.com/remcostoeten/dora/releases/latest).
</Callout>

## Platform matrix

| Platform   | Architectures        | Package                                            | Package managers             |
| ---------- | -------------------- | -------------------------------------------------- | ---------------------------- |
| macOS      | Apple Silicon, Intel | Universal `.dmg`                                   | Homebrew                     |
| Windows    | x64, ARM64           | Setup `.exe`                                       | Winget, Scoop                |
| Linux      | x86_64, ARM64        | `.AppImage`, `.deb`, `.rpm`, `.flatpak`, `.tar.gz` | APT, DNF, Flatpak, Snap, Nix |
| Arch Linux | x86_64, ARM64        | AUR                                                | `yay -S dora`                |

ARM64 builds for Windows and Linux ship when that release built them; x64 and
x86_64 ship with every release.

## macOS

1. Download the universal DMG. It runs natively on Apple Silicon and Intel.
2. Open the DMG and drag **Dora** into your Applications folder.
3. Launch Dora from Applications.

<Callout type='warn'>
	Dora is not notarized, so macOS blocks the first launch. Open Dora once, close the warning, then
	go to **System Settings → Privacy & Security** and click **Open Anyway** next to the message
	about Dora. This only needs to be done once. Homebrew installs skip this step because the cask
	clears the quarantine flag.
</Callout>

### Homebrew

```bash
brew install --cask remcostoeten/dora/dora
```

## Windows

1. Download the setup installer for your architecture (x64 or ARM64).
2. Run the installer. If SmartScreen warns about an unrecognized app, choose
   **More info** then **Run anyway**.
3. Launch Dora from the Start menu.

### Winget

```powershell
winget install RemcoStoeten.Dora
```

### Scoop

```powershell
scoop bucket add dora https://github.com/remcostoeten/dora-packages
scoop install dora/dora
```

## Linux

Pick the package that fits your distribution:

| Package         | Install command                                       |
| --------------- | ----------------------------------------------------- |
| AppImage        | `chmod +x Dora_*.AppImage && ./Dora_*.AppImage`       |
| Debian / Ubuntu | `sudo apt install ./Dora_*.deb`                       |
| Fedora / RHEL   | `sudo dnf install ./Dora-*.rpm`                       |
| Flatpak bundle  | `flatpak install --user ./Dora-*.flatpak`             |
| Snap            | `sudo snap install dora`                              |
| Archive         | `tar -xzf dora-*.tar.gz` and run the extracted binary |

The repositories below give you updates through your package manager instead of
re-downloading each release. All of them are signed with the same key,
[KEY.gpg](https://remcostoeten.github.io/dora/KEY.gpg).

### APT (Debian / Ubuntu)

```bash
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://remcostoeten.github.io/dora/KEY.gpg | sudo gpg --dearmor -o /etc/apt/keyrings/dora.gpg
echo "deb [signed-by=/etc/apt/keyrings/dora.gpg] https://remcostoeten.github.io/dora stable main" | sudo tee /etc/apt/sources.list.d/dora.list
sudo apt update && sudo apt install dora
```

### DNF (Fedora / RHEL / openSUSE)

```bash
sudo curl -fsSL -o /etc/yum.repos.d/dora.repo https://remcostoeten.github.io/dora/rpm/dora.repo
sudo dnf install dora
```

On openSUSE, add the same file with `sudo zypper addrepo https://remcostoeten.github.io/dora/rpm/dora.repo`.

### Flatpak

```bash
flatpak install --user https://remcostoeten.github.io/dora/flatpak/io.github.remcostoeten.dora.flatpakref
```

The ref adds the Dora remote and, when it is missing, Flathub for the GNOME
runtime. Updates then arrive through `flatpak update`.

### Nix

```bash
nix profile install github:remcostoeten/dora-packages
# or try it without installing
nix run github:remcostoeten/dora-packages
```

### Arch Linux (AUR)

Dora is published to the AUR as [`dora`](https://aur.archlinux.org/packages/dora)
as a prebuilt binary. Install it with any AUR helper:

```bash
yay -S dora
# or
paru -S dora
```

### Rendering on Linux

Dora draws its interface with WebKitGTK and picks the rendering path at
startup:

| Session                              | Path                                   |
| ------------------------------------ | -------------------------------------- |
| Wayland                              | Native Wayland window, GPU compositing |
| X11, largest display up to 2560x1600 | GPU compositing through shared memory  |
| X11 with a larger display            | Software rendering                     |
| Flatpak, Snap or AppImage            | Software rendering                     |

If a GPU path never paints a frame, Dora restarts itself with software
rendering and keeps using it until the next update.

Set `DORA_RENDERER` to choose a path yourself:

```bash
DORA_RENDERER=wayland dora    # native Wayland, GPU
DORA_RENDERER=gpu dora        # X11, GPU through shared memory
DORA_RENDERER=software dora   # X11, CPU only
```

`GDK_BACKEND` and `WEBKIT_DISABLE_DMABUF_RENDERER` are respected when you set
them. The log names the path in use, in a line starting with `Linux renderer:`.

On NVIDIA drivers WebKitGTK paces frames with a 60 Hz timer, so 60 fps is the
ceiling there whatever the monitor's refresh rate.

## Verify the install

Launch Dora and open **Settings → About** to confirm the version matches the
release you downloaded. On Linux you can also check the binary:

```bash
dora --version
```

## Build from source

To build Dora yourself you need the Rust toolchain (`cargo`) and Node.js with
`pnpm`.

<Callout type='info'>
	Building from source produces an unsigned binary intended for development. For day-to-day use,
	prefer a prebuilt release.
</Callout>

1. **Clone the repository**:

    ```bash
    git clone https://github.com/remcostoeten/dora.git
    ```

2. **Install dependencies**:

    ```bash
    pnpm install
    ```

3. **Run the desktop app**:

    ```bash
    pnpm desktop:dev
    ```

4. **Run these docs locally**:

    ```bash
    pnpm docs:dev
    ```
